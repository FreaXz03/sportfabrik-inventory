**Priority: next work item, explicitly requested by Fabian on 2026-09-29.** Complete this redesign before the previously queued feature extensions and store-deployment work. Mandatory deployment checks still apply before any deployment. This is a new structural redesign request, not a claim that the earlier UI redesign already fulfils it. ## Scope and visual references

- Redesign the layout of all pages around the structure in reference 1, especially the left sidebar. Keep the existing colors, visual elements and design language; do not copy the reference's brown palette or IMS branding.
- Keep the existing Sportfabrik logo above the sidebar, with SPORT-FABRIK above INVENTORY as in reference 2.
- Rename and regroup navigation according to reference 3 (exact German labels below; retain DE/FR/EN translations).
- Add a search bar at the top for finding all app functions. Respect existing permissions; this request does not grant access to restricted functions.
- Add dashboard charts inspired by reference 1: a time-series stock overview and a category-distribution donut. Use real Sportfabrik data and understandable labels; screenshot figures/categories are illustrative, not business data. Reuse existing dashboard data where appropriate; detailed metrics/time ranges remain implementation planning.
- Open Settings in a small centered modal instead of navigating to a separate page.
