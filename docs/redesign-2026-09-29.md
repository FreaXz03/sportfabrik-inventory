- Rename and regroup navigation according to reference 3 (exact German labels below; retain DE/FR/EN translations).
- Add a search bar at the top for finding all app functions. Respect existing permissions; this request does not grant access to restricted functions.

Use real Sportfabrik data and understandable labels; screenshot figures/categories are illustrative, not business data. Reuse existing dashboard data where appropriate; detailed metrics/time ranges remain implementation planning.
