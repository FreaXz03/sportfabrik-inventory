Sportfabrik Warenwirtschaft

Jede Ware wird beim Eingang einmal erfasst — per Upload des Belegs (Rechnung, Lieferschein, Auftragsbestätigung) oder von Hand mit dem Scanner. Danach weiss das System dauerhaft, welcher Artikel zu welchem Preis wann geliefert wurde und wie viel davon in welcher Filiale liegt. Selbst gebaut, läuft auf unserem eigenen Server, ohne Lizenzgebühren — Belege verlassen das Haus nie.

  • 4 + 3Filialen und externe Standorte (GEWA, VEBO, Dietikon)
  • 35Kassenkategorien 1:1 wie an der Kasse
  • 3Sprachen: DE / FR / EN
  • ~20Arbeitsplätze in allen Filialen
  • 3 von 7Phasen fertig: Fundament, Wareneingang, Bestand

Was möglich ist

  • läuft bereits
  • geplant, Phase D–G

Ware erfassen Eingang

  • Beleg als PDF hochladen, auch mehrere auf einmal
  • Positionen werden automatisch ausgelesen — Vorschau zum Prüfen und Korrigieren, erst dann wird gebucht
  • Eingescannte Belege über Texterkennung, unsichere Felder markiert
  • Auftragsbestätigung bucht noch keinen Bestand, sondern einen erwarteten Eingang — „Ware eingetroffen" bestätigen darf jeder, Restmengen bleiben offen
  • Lieferant, Belegart und Ziel-Lagerort werden aus dem Dokument erkannt und vorgeschlagen
  • Ware ohne Beleg von Hand per Scanner erfassen — Marke, Bezeichnung, Menge, UVP genügen
  • Warnung, wenn mehr eintrifft als erwartet
  • Parser für Alpina, Chris Sports und CMP vorhanden; weitere Händlerlayouts und ECOM-Erkennung bleiben separat zu prüfen

Artikel & Preise Nachschlagen

  • Artikel aus Belegen bleiben dauerhaft nachschlagbar — Ausnahme für manuelle Fehleinträge siehe unten
  • Einfache Suche: grosses Feld „EAN scannen" ist sofort aktiv, dazu eine Schnellsuche — weitere Filter eingeklappt
  • UVP-Verlauf je Artikel, Einkaufspreis wenn im Dokument vorhanden
  • Lieferhistorie über alle Farben und Grössen, Notizen am Artikel, Excel-Export
  • Kassenkategorie wird aus dem FEDAS-Code vorgeschlagen, sonst von Hand gewählt — Filter „Ohne Kategorie"
  • Lieferantengruppen mit Code 111 / 555 / 333 / 999 / 444
  • Falsch von Hand erfasste Artikel darf die Filialleitung ganz löschen — Artikel aus Belegen bleiben
  • FEDAS-Zuordnung ergänzt: 54 Erlebnisbereiche zugeordnet; Kids bleibt manuell

Lager & Bestand je Filiale

  • Bestand je Filiale und Variante — SF1–SF4 plus GEWA, VEBO, Dietikon; alle Filialen lesbar
  • Jede Änderung ist eine Bewegung, Bestand wird nie einfach überschrieben
  • Umlagerung: die empfangende Filiale bucht; extern → Filiale setzt das Eingangsdatum, Filiale → Filiale behält es
  • Verkauf und Abgang per Scan ausbuchen — ein Scan, ein Stück, mit Grund; Liste aller Ausbuchungen mit Zeit und Person
  • Korrektur: Menge im Regal zählen, das System bucht die Differenz
  • Inventur für ganze Filialen per Scanner

Runterschreiben 30 / 50 / 70 %

  • ‑30 % ab Eingang, ‑50 % nach 18 Monaten, ‑70 % nach 36 — Stufe wird bereits berechnet und steht fürs Etikett bereit
  • Gerechnet pro Filiale, ab dem letzten Wareneingang derselben Artikelnummer — eine Nachlieferung startet die Uhr neu
  • Übersicht zeigt unter „Anstehend", was ‑50 % / ‑70 % erreicht hat oder in 30 Tagen erreicht
  • Eigene Liste „zum Runterschreiben fällig", direkt zum Etikettendruck
  • Zentrale Empfehlung für alle Filialen; jede Filiale entscheidet selbst, Abweichungen bleiben sichtbar
  • Die Schwellen 18 und 36 Monate sind einstellbar

EAN & Etiketten Scanner

  • EAN kommt aus dem Dokument; Varianten ganz ohne EAN funktionieren
  • EAN jederzeit per Scan nachtragen
  • Fehlt sie: auf Knopfdruck eine eigene, interne EAN erzeugen
  • Etikett als PDF — UVP, Lieferanten-Code, Jahrgang und Strichcode; das System sagt, welche Rolle (30 / 50 / 70 %) einzulegen ist
  • Etikett 47 × 83 mm auf vorgedruckten Farbrollen — laut lokalem Projektkontext umgesetzt
  • Funk-Scanner an jedem PC, ohne Zusatzsoftware — Testgerät noch zu beschaffen

Bedienung Alltag

  • Anmeldung wie an der Kasse: Kassennummer, Passwort für Leitung und Zentrale
  • Deutsch, Französisch, Englisch — Oberfläche und Fehlermeldungen
  • Aufgeräumte Kopfzeile mit Menü in Gruppen, Filialwechsel und Konto-Menü
  • Übersicht mit grossen Schnellzugriffen, Kennzahlen der Filiale, „Anstehend" und „Aktuelles"
  • Mitarbeiter dürfen alles ausser Belege hochladen — Filialleitung zusätzlich Belege
  • Gut lesbar auch mit Brille: Hell-/Dunkelmodus, grössere Schrift, wählbare Spalten

Betrieb eigener Server

  • Läuft auf einem eigenen Server im Geschäft — Belege liest nur unser eigener Parser, keine Lizenzgebühren
  • Funktioniert im Ladennetz auch dann, wenn das Internet ausfällt
  • Automatische Backups; Ablauf-Tests prüfen bei jeder Änderung alle Hauptabläufe
  • Server Volketswil produktiv, gesicherte Verbindung (VPN) zu den Filialen
  • Zusätzliche Backups ausser Haus

Kasse das Endziel

  • Scan an der Kasse liefert Kategorie, UVP und die aktuelle Reduktionsstufe
  • Der Verkauf bucht den Bestand automatisch aus
  • Kein manuelles Eintippen von Kategorie, Preis und Prozent mehr
  • Hängt an der Abklärung mit Intersport — Zugriff und Schnittstelle sind offen

Fahrplan

Die Reihenfolge ist nicht beliebig: ohne Fundament kein Wareneingang, ohne Wareneingang kein Bestand, ohne Bestand keine Reduktion.

  1. A · fertigFundamentFilialen, Rollen, Sprachen, Datenmodell
  2. B · fertigWareneingangBelegarten, Erkennung, Scanner, EAN
  3. C · fertigBestandUmlagerung, Ausbuchen, Korrekturen
  4. D · als NächstesReduktionPreisverlauf, 18-/36-Monats-Hinweise
  5. ELieferantenweitere Layouts und Scans
  6. FBetriebServer, VPN, Backups, Umzug
  7. GKasseAnbindung Intersport

Worauf wir bewusst verzichten

  • Keine KI für BelegeJeder Beleg wird von unserem eigenen Parser auf dem eigenen Server gelesen. Keine Rechnung, kein Lieferschein verlässt das Haus. Ein unbekanntes Layout wird gemeldet, nicht geraten.
  • Keine Standard-SoftwareSie würde unsere Kassenkategorien, die 30/50/70-Logik und die externen Standorte GEWA, VEBO und Dietikon nie genau abbilden — und kostet laufend.
  • Kein Bestand auf VerdachtGebucht wird erst, wenn die Ware wirklich eingetroffen ist. Eine Auftragsbestätigung ist nur eine Ankündigung.
